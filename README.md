# AMC-Sustainable-AI-
Reproducible experiments &amp; supplementary materials for Adaptive Model Continualization (AMC): energy- and carbon-aware continual learning with pruning, quantization, and statistical validation.
Supplementary code, data, and figures for the paper “Adaptive Model Continualization for Sustainable Artificial Intelligence with Reduced Energy Consumption and Carbon Footprint”. Includes Kaggle-runnable notebooks, 5-run statistics, ablation studies, carbon-intensity proof-of-concept, and reviewer-response tables.
